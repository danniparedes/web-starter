Form kit

Every field type a project usually needs. Keep the groups you need, delete the rest.

How to use this kit

  1. Copy the whole <form> into your page.
  2. To hide a group without deleting it, set its switch to false in js/site-config.js (for example 'form.address': false). Set it back to true to show it again.
  3. Each block between GROUP n comments is one <fieldset class="form__group">. Delete the blocks you do not need; a single field can be deleted on its own too.
  4. Required fields: add required to the control and form__label--required to its label.
  5. Field names (name="...") are what the PHP side receives. Keep them stable once PHP exists.
  6. The spam-trap field is named website, so the real web address field is called website_url.
